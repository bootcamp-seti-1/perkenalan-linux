1. mkdir (Make Directory)
Perintah ini digunakan untuk membuat folder baru di dalam direktori saat ini.
Penggunaan: mkdir folder_baru

2. cp (Copy)
Perintah ini digunakan untuk menyalin (duplikasi) file atau folder dari satu tempat ke tempat lain.
Penggunaan: cp P00-date.md folder_baru/

3. mv (Move & Rename)
Perintah mv memiliki dua fungsi utama: 
 - memindahkan file/folder ke lokasi lain,
 - mengubah nama (rename) file/folder tersebut.
Penggunaan: mv date.md folder_baru/

4. rm (Remove)
Perintah ini digunakan untuk menghapus file atau folder. File atau folder yang dihapus menggunakan rm akan terhapus secara permanen dan tidak masuk ke Recycle Bin.
Penggunaan: rm date.md
